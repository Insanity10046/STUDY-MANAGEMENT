# Machine Method V2
## Core Loop
> Broad Scaffold -> Aggressive Mixed Practice -> Immediate Error Signal -> Refine scaffold -> Fade aids -> Closed-book test -> Final summary from memory
This refined version, keeps the original Machine Method's aggression and efficiency but adds:
- all-at-once mixed practice
- compressed feedback loops
- fading cheatsheets and mindmaps
- final summary written only after true mastery.

## PHASES
---
### Phase 0 -- Broad Scaffold
Create a rough, big picture summary of the **whole domain**, not one topic at a time. Think the pillars of the domain, the universal processes.
#### Example -- Algebra
> Algebra is preserving equivalence while isolating unknowns.  
> Algebra focuses on the mathematical statements(equations, expressions, inequalities, systems) all of which have structures in them(geometric structures).  
> Equations use inverse operations, inequalities add sign-reversal rules, system reduces to one equation via substitution/elimination, and expression are simplifed not solved.

This is a generative summary, not a fact list(you will constantly refine this).

#### RULE
Do **not** over-refine this step. It is a scaffold, the refinement happens through errors(feedback loop).

---
### Phase 1 -- Fading Cheat sheet and Mindmap
Convert the broad scaffold into two external supports.
#### 1. **Structured cheat-sheet**
Use condition-action rules.
> IF dividing by a negative -> flip inequality  
> IF both equations isolate the same variable -> use substitution.  
> IF no equation/inequality -> only simplify.

#### 2. **Mindmap**
Show relationships among topics or pillars.
> Algebra -> Equations, Inequalities, Systems, Expressions  
> Systems -> Substitution, Elimination  
> Inequalities -> Sign Reversal, Inverse Operations
These supports reduce cognitive load during early mixed practice.

---
### Phase 2 -- Aggressive All-at-Once Mixed Practice
Do **not** study topics separately. Mix everything(by utilising all the pillars of the domain) from the start.  
For example, **Algebra**:  
- Mix equations, inequalities, systems, and expressions in every session.
- Attempt each problem from memory first for 30-60 seconds.
- If stuck, consult the cheat sheet or mindmap.
- Solve.
- Check answer immediately(feedback loop).
This forces **discrimination** and **prevents illusion of mastery or Dunning Kruger effect** that topic-by-topic study creates.

---
### Phase 3 -- Compressed Feedback Loop
This is the engine of the whole method.
> Attempt -> Observe outcome -> Compare -> Detect mismatch(Broad Scaffold, Mindmap, Cheatsheet vs. Generated ones) -> Refine scaffold -> Repeat
#### Compressed Feedback
Use:
- model answers
- past exam solutions
- expert critique
- simulations
- after-action reviews
- proficiency tests
- red-team exercises
Do not wait for real word outcomes when you can **create faster error signals**.

#### Refine at the point of error
Every mistake updates the cheat sheet, mindmap, or broad summary.  
Example:
> Mistake: forgot to flip inequality wwhen dividing by negative.  
> Refinement: strengthen the condition-action rule "IF dividing by negative -> flip
The scaffold becomes more precise with every error.

---
### Phase 4 - Fading Supports
Do not let the cheat-sheet become a crutch.
#### Fade-in layers protocol:
1. Remove examples
2. Remove minor-details.
3. Remove rule names, keep triggers.
4. Remove triggers, keep only section headings.
5. Remove the cheat-sheet entirely.

#### Reconstruct the mindmap from memory
Before or after practice, draw the whole structure from memory.
- Compare with the original
- Fill in gaps.
- Repeat until you can reconstruct it fully.
This builds retrieval strength while keeping the borad structure intact.
