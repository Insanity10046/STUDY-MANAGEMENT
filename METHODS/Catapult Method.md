# Catapult Method
The main idea of this learning system is that, you set the launchpad first, slowly setting up ur thruster before exploding upward aggressively.
### Rule:
- Write every topic of the subject first, don't learn it but just write it.
- After writing every topic, aggressively learn the subject on the topics you've wrote. Forcing active learning.
- Aggressive learning the subject based on the things you've wrote means aggressive problem solving too.
 
 
| Pros                                  | Cons                                                                                                   |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Easy comprehension                    | Slow pace. Writing takes a long time.                                                                  |
| Immediate quick review                | Shaky foundations due to delaying learning first                                                       |
| Relaxed status before forced learning | Illusion of learning on writing                                                                        |
|                                       | Notes has to be rewritten again if the writing about the topic is wrong or has slight false conclusion |
|                                       |                                                                                                        |
