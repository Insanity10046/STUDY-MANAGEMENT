# Bloom's Taxonomy
C-3:
#### PHASE 1: Diagnostic Set (Establishing Baseline)
**Purpose:** Create initial neural pathways and identify starting points
- **Remember:** Create active recall questions (Anki cards) for essential facts
- **Understand:** Write a one-paragraph explanation in your own words
- **Apply:** Solve 2-3 standard problems using basic procedures
 
#### PHASE 2 Cognitive Cycle:
- Attack from 2+ levels higher(Analyze/Evaluate)
- Identify the precise fracture point revealed by failure
- Reinforce that specific weakness with targeted practice 
- Retest at the higher level to verify repair
 
 
**Fracture Point Identification (Concise Guide):**
 
- **If you fail at ANALYZE:** 
  - Can't break down concepts? → **UNDERSTAND** fracture
  - Miss connections between parts? → **REMEMBER** fracture (missing facts)
  - Can't organize information? → **APPLY** fracture (procedure gap)
 
- **If you fail at EVALUATE:**
  - Can't critique arguments? → **ANALYZE** fracture (can't see components)
  - Lack criteria for judgment? → **UNDERSTAND** fracture
  - Can't defend your position? → **APPLY** fracture (can't use evidence)
 
- **If you fail at CREATE:**
  - Can't generate new ideas? → **EVALUATE** fracture (poor judgment of options)
  - Can't synthesize elements? → **ANALYZE** fracture (can't see relationships)
  - Can't organize coherently? → **APPLY** fracture (structural weakness)
