A skill level system, called
**NAPE Framework**
| Tier | Level | Title            | Description                                                                        |
|------|-------|------------------|------------------------------------------------------------------------------------|
| N    | N1    | Novice           | Follows step by step instructions under supervision                                |
|      | N2    | Beginner         | Completes simple, routine tasks using basic rules.                                 |
|      | N3    | Advanced Beginner| Recognizes patterns in tasks; performs straightforward tasks independently.        |
| A    | A1    | Practitioner     | Works independently on standard tasks and common problems                          |
|      | A2    | Adept            | Handles varied, complex tasks; optimizes processes; guides novice                  |
|      | A3    | Advanced         | Solves complex non-routine problems; integrates knowledge across areas.            |
| P    | P1    | Proficient       | Sees the "big picture"; leads projects; innovates within the field.                |
|      | P2    | Expert           | Deep intuitive understanding; solves novel problems; sets standards.               |
|      | P3    | Scholar          | Shapes field practices; publishes insights; defines methodology                    |
| E    | E1    | Elite            | Top authority; work pushes field boundaries                                        |
|      | E2    | Master           | Synthesizes knowledge across fields to create new paradigms.                       |
|      | E3    | Visionary        | Defines the future of the field; ideas create new direction                        |
| T    | T1    | Genius           | Top of the arts; innovative; transcendental mastery                                |
|      | T2    | Think-Tank       | The final level, culmination of E3 & T1                                            |

**Academic Marker**:
- HS - HIGH SCHOOL
- C - COURSE
- UG - UNDERGRAD

This suffix is optional and can only be used when it applies.  
**USE IT WHEN** a formal academic course, degree, or standardized examination was used as part of the learning process or **objective evidence** for reaching that skill level.  
**DO NOT USE IT WHEN** the skill level itself was gained through self study, work experience, bootcamp, or project.
