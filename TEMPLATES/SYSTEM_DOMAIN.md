## SESSION CYCLE — DOMAIN LEVEL

| Stage | Action |
|---|---|
| Pre-session | Review Domain Architecture and current map |
| Active session | Execute Procedure Matrix steps according to Study System Rules(Method Configuration) |
| Post-session | Update Obsidian map, error log, and case notes |
| Next session | Choose next subdomain or comparison case |

---

**Core Rule:**  
Study the domain from the **map down to cases**, then from **cases back to the map**. The Study System Rules govern how that movement happens.
