# DERIVATION / ANALOGICAL LEARNING
**“derive, don’t learn” means**: when encountering a new domain, you first extract its deep functional structure and map it onto schemas you already possess. Then you only have to learn the new surface vocabulary and syntax—the underlying logic is **derived** from what you already understand, drastically reducing what must be memorised.
### The Analogical Learning Process
It’s not a single event; it’s a deliberate cognitive workflow that spans the first two phases of the Accelerated Acquisition Cycle. The goal is to make “derive, don’t learn” a literal reality.

**Step 1 – Schema Extraction (done first, before any detail learning)**
- **When:** Phase 1, which uses 1–5% of total learning time.
- **What you do:** You acquire *one* top-level expert overview of the new domain (a master practitioner’s mental model, a flowchart, an interview). You do not yet learn any vocabulary, facts, or procedures. Instead, you ask: “What is the central problem this domain solves? What are its basic entities and rules? Which of my existing skills have the same functional architecture?”
- **Output:** You produce a one-page ontological map that explicitly states the deep structural analogy. Example from the text: *“Legal prosecution is functionally identical to a military siege: you must attack a fortified position (the defendant’s narrative) with limited resources (admissible evidence) while protecting your own vulnerabilities (burden of proof, procedural errors).”*
- **Why first:** This map becomes the framework that “governs all subsequent learning.” It pre-loads the brain so that everything new is automatically perceived as an instance of something already understood.

**Step 2 – Hook experience before labels (still early, still minimal detail)**
- **When:** Very beginning of Phase 2.
- **What you do:** You immediately apply the skill in a trivial but real context, using only transfer from existing domains. For example, learning tradecraft: first session is conducting a one-hour physical surveillance exercise using just psychology and urban fieldcraft. The domain-specific terminology (e.g., “SDR”) is deliberately withheld until *after* you have the raw experience. This ensures the new labels attach to a concrete, schema-linked memory rather than floating abstractions.

**Step 3 – Analogical encoding during progressive integration**
- **When:** Throughout Phase 2, as you now learn the “minimum effective dose” of domain-specific vocabulary and procedures.
- **What you do:** This is the core technique. The text says:
  > “Every time a new procedure is introduced, the agent pauses and writes down **how it’s exactly the same as something already known, and the one crucial way it’s different.** This builds a precise, non-overwriting mental model.”
- **Cognitive effect:** You are not memorising a new stand-alone skill. You are deliberately extending and *differentiating* an existing schema. This prevents negative transfer (where the old schema would overwrite the new nuance) and builds a rich, accurate representation with minimal effort.

**Step 4 – Maintain the network via forced analogy practice (ongoing)**
- **When:** Weekly, as part of the Maintenance Protocol.
- **What you do:** Pick two random skills from the ontology and write a brief note on their deep structural commonalities. This keeps the entire network of analogical links active and ready to “derive” new skills in the future.
### So, the definition of the whole process in one sentence:

**Analogical learning is a meta-strategy in which you first identify the deep functional structure of a new domain and explicitly map it to an already-mastered schema (schema extraction), then, as you encounter each new specific procedure, you consciously anchor it to that map by noting how it is structurally identical to something known and precisely how it differs (analogical encoding), thereby deriving competence from your existing semantic network rather than building it from scratch.**

The key distinction: schema extraction sets the *macro* analogy before studying; analogical encoding applies the *micro* analogies *while* studying. Both together make “derive, don’t learn” operational.
