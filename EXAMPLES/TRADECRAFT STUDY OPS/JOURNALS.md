**Use order during practice:**

1. Free recall attempt first
2. If stuck on what to do -> consult Conditional-Action Cheatsheet
3. If a term is unclear -> consult Lexical Cheatsheet
4. If you need to see consequences or cross-branch effects -> consult Relational Mindmap
5. Only if lost or unsure what topic a scenario touches -> consult hierarchial mindmap

**Rule**:
> **Action first, meaning second, consequences third, location last.** never start with the mindmaps. Always attempt unaided before opening any scaffold. 

**Refinement priority:**

Relational map > decision cheatsheet > lexicon > hierarchical map.

Example of Relational mindmap:

> High Cover Inconsistency
> -> increases Surveillance interest
> -> forces longer SDR
> -> delays Dead Drop
> -> increases Communication urgency

This is a **loop**, not a tree.
