# Transfer of Learning 
> Transfer of Learning is the ability to take knowledge or skills learned in one context and apply them effectively to a new, different context.
---
# Types of Transfer:
- Near Transfer: Applying knowledge to a closely related context.
**Example**: Using your algebra skills in a calculus class.
 
- Far Transfer: Applying knowledge to a very different for context.
**Example**: Using the logical structure of a mathematical proof to build a coherent legal.
 
- Positive Transfer: When previous learning helps new learning.
**Example**: Knowing Spanish helps you learn Italian.
 
- Negative Transfer: When previous learning interferes with new learning (less common).
**Example**: A driver used to a manual transmission stalling an automatic car because they reach for a non-existent clutch pedal.
 
# Techniques utilising Transfer of Learning:
1. Concept Mapping
2. Interleaving
3. Combined Topic Problemset
4. Interleaved Practice
 
***In essence, if "learning" is storing information in your brain, "transfer of learning" is building a sophisticated indexing and retrieval system that allows you to use that information anywhere it's needed.***
